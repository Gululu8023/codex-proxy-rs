# v4.0.6

## 分组模型权限与子代理控制

- 账号分组新增模型白名单、黑名单，按映射后的完整上游模型 ID 与账号自身权限共同校验，并同步过滤客户端模型目录。
- 分组新增 Codex 子代理开关；任一绑定分组关闭后，模型目录关闭协作能力，HTTP 与 WebSocket 执行入口拒绝协作子线程生成请求。父线程工具历史、review、compact 和 Guardian 请求不受该开关影响。

## API Key 管理与统计

- 新增批量编辑，支持分组、启用状态、并发、频率、日／周预算、共享设置及客户端画像；未提交的字段逐把保留，任一 Key 无效时整批回滚，不清零已用费用或重置已有预算窗口。
- 新增单 Key 的 7 天／30 天模型统计，可按费用、Token 或请求数查看趋势和明细；趋势与明细共用查询时间，缺失费用保留未知标记。
- 支持 Anthropic 的 Key 客户端画像与安装身份种子；后台账号操作使用执行时的 Provider 全局画像。
- 请求历史新增错误来源筛选，依据请求当时保存的错误事实区分上游、代理、连接和未知来源。

## 模型与计价

- 新增 Claude Fable 5.2、Mythos 5.2 的标准、Fast 与缓存计价，以及 GPT-6.2 Astra／Sol 的标准、Fast、Ultrafast 和长上下文计价。
- GPT-6.2 Ultrafast 内置价固定为对应标准价的 6 倍，长上下文同样适用，不随临时优惠修改。人工覆盖优先于同步价，再回退内置价；本地估算不改变上游请求或实际扣费策略。
- 新价目用于后续请求，历史记录继续展示请求当时保存的计费事实；模型可用性仍由实际账号目录和权限决定。

## 流式传输与账号状态

- 流式响应结束或出错后及时释放上游并发槽位，避免等待持久化继续占用容量；改进 WebSocket 上传、读取、关闭码处理和安全续写。
- 明确收到访问令牌撤销证据时缩短其有效期，并保留刷新计划；同一令牌的并发写回不能覆盖已确认的撤销事实。
- 额度耗尽时保留上游明确指出的窗口时长，恢复时按对应窗口证据复核；同一上游身份重新授权保留既有额度事实。
- 模型目录按一小时周期复核，使用 ETag 续期以减少重复获取。

## 升级说明

- 从 v4.0.5 升级无需新增配置。启动时自动应用 `0004_quota_limit_window.sql` 和 `0005_account_group_policies.sql`，分别增加额度耗尽窗口和分组权限字段。
- 既有分组默认允许全部模型和子代理，升级后可按需收紧权限。
- 沿用现有配置、PostgreSQL、Redis 和运行数据，包括 Veil 主密钥与映射；CPRS 初始化基线仍不兼容源仓库历史数据库。
