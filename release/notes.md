# v4.0.5

## Claude 响应恢复

- 修复 Claude 回复中的未知脱敏占位符导致响应中断或返回 503 的问题，覆盖流式、非流式响应及工具参数。
- 未知占位符原样返回，已知映射照常还原；保留真实存储、解密和协议错误的处理，并补充不含正文的还原诊断信息。

## 请求历史

- 新增“Token 计数”胶囊，便于识别客户端的 Token 计数请求，管理端和 Key 自助页面均支持展示。
- 按实际请求模式记录 JSON／SSE 协议，修复 Token 计数请求和非流式 Claude 请求被误标为 SSE 的问题。

## 构建与发行

- CI 统一生成并验证发布产物，Docker 发布直接复用已验证的镜像，减少重复编译后端和构建镜像。
- 正式发行优先复用同一提交的前端、amd64 二进制和镜像；产物有效时仅补建 arm64，缺失或过期时重新构建。继续保留两个架构的容器验证、产物证明和发布校验。
- 定期 Security 检查直接扫描已发布的 `latest`／`stable` 镜像，保留依赖审计与漏洞检查，避免为安全扫描重新构建应用。

## 升级说明

- 从 v4.0.4 升级无需新增配置，本次不包含新的数据库迁移。保留现有配置、PostgreSQL、Redis 和 `.runtime/data`，包括 Veil 主密钥与映射。
- JSON／SSE 协议记录的修正对升级后的新请求生效，已有历史记录中的协议标签不回写。
