# v4.0.4

## Claude 额度与调度

- 修复额度重置后账号仍停留在耗尽状态：区分 OAuth 明确的零用量空重置时间与缺失／无效观测，复用并发校验恢复账号和阈值暂停。
- 修复不完整额度查询覆盖已知重置时间的问题：5h／7d 达到上限时保留仍有效的周期；区分缺字段、明确零用量和新周期，不补造窗口时间。
- 完整 HTTP 429 的账号／模型限流可在同一请求内按既有预算切换账号；保留原始错误、冷却、指定账号限制及流式交付边界。

## 统计费用

- Claude 缓存净节省和标准费用使用请求时的计费快照计算，保留 5 分钟／1 小时缓存写入的实际分项，不使用当前价格重算历史。
- 费用差额仅比较同一批可核验请求，支持零值及负净节省，并显示可比请求覆盖率。Claude 金额为 API 等价估算，不代表订阅现金节省。
- 新增追加迁移，通过现有版本化投影队列分批补算仍留存的历史记录，不清空已有汇总；快照缺失的差额保持未知。

## 安全与发行

- 将 cookie 更新至 0.18.3、url 更新至 2.5.9，修复 RUSTSEC-2026-0594 和 RUSTSEC-2026-0592；保留定期 Security 审计。
- 复用当前发行提交已经通过的后端质量检查，避免发布流程重复执行相同检查。

## 升级说明

- 启动时自动应用 `0003_recorded_billing_comparisons.sql`；历史费用补算由后台分批完成，完成前可比覆盖率会逐步更新。
