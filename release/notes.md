# v4.0.1

## Claude 账号、套餐与模型目录

- 修正 Claude OAuth 和凭据导入生成的账号 ID 缺少 `acct_` 前缀导致创建失败的问题。
- 按官方组织信息识别 Pro、Max、Team 和 Enterprise 套餐，补全 OAuth 资料，并随额度刷新修正已有账号缺失的套餐。
- Claude 账号共享额度显示为“通用额度”，列表与详情不再直接显示内部标识 `account`。
- 模型目录在缓存硬过期前提前刷新，避免正常周期采集等待缓存失效后才补采。
- 账号导入、授权和令牌轮换提交后立即通知后台采集新凭据版本的目录；通知合并、取消和失败退避由宿主监督。
- 保留账号与凭据版本隔离、权限复核和 veil 门禁，采集失败不延长旧目录缓存，也不回滚已提交的账号变更。

## 安装兼容性

- 一键安装读取容器用户 UID/GID 时，通过临时 Compose 配置禁止拉取镜像，兼容不支持 `compose run --pull` 的旧版 Compose。
- 重复执行安装脚本继续保留已有部署文件、镜像和容器，镜像升级仍按部署文档单独执行。

## 升级须知

- 从 CPRS `4.0.0` 升级无需新增数据库迁移或重建数据库；已发布迁移文件保持不变。
- 使用原部署目录拉取新镜像并重建应用容器，保留配置、PostgreSQL、Redis 和 `.runtime/data`，尤其是 veil 主密钥及映射数据。
