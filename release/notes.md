# v4.0.2

## Claude 响应可靠性

- 补齐原生 JSON 与 SSE 文本块声明，避免正常响应在记录用量时被误判为协议错误。
- 流式成功终帧等待结算和租约释放完成后再交付；收尾失败只返回失败终态，取消等待不会丢失终帧。
- 本地协议错误、上游服务故障和过载不再误扣账号健康分。

## 推理配置与用量展示

- 分别记录和显示 Claude 显式推理强度、思考模式与 token 预算，同时覆盖管理端和 Key 自助用量页。
- 新请求未指定配置时显示“未指定”，旧记录继续显示未知；不根据模型、思考模式或预算猜测强度。
- 仅记录上游明确返回的思考 token 数，不重复累加输出 token 或费用。

## 隐私处理与性能

- Claude 请求发送前预留 veil 容量，脱敏、错误恢复与流式恢复共用许可；取消和超时后由实际工作线程持有许可直到退出。
- 普通文本脱敏增加按 Key 隔离的有界内存缓存和请求内映射复用，减少长对话的重复扫描与写入。
- 暖缓存发送前校验持久映射的归属和完整性，签名、思考块及工具 schema 保持原有协议边界。
- 补充脱敏耗时观测、相关回归用例及前端 CI 测试步骤。

## 升级须知

- 从 CPRS `4.0.1` 升级时，服务启动会自动执行新增迁移 `0002_claude_request_observation.sql`，无需重建数据库或回填历史记录；原有迁移文件保持不变。
- 使用原部署目录拉取新镜像并重建应用容器，保留配置、PostgreSQL、Redis 和 `.runtime/data`，尤其是 veil 主密钥及映射数据。
- 升级前保留数据库备份。迁移执行后不能直接切回缺少 `0002` 的旧镜像；回退需要恢复升级前的数据库与匹配镜像，不能删除迁移记录绕过校验。
