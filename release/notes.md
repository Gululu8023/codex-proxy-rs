# v4.0.0

## CPRS 独立版本

- CPRS 从 v4.0.0 开始独立编号，不再沿用源仓库版本号。后续按 CPRS 自身的功能与兼容性变化递增版本。
- Codex 与 Claude Code 共用账号、客户端密钥、计量、审查和管理界面；Claude 使用同进程 veil 保护出站请求与会话映射。

## 请求恢复与记录查询

- 修正无 HTTP 状态码的流内参数错误分类，避免误换号、冷却或记为上游不可用。
- Codex WebSocket 瞬时建连失败可在现有预算内恢复；确认代理 TCP 入口不可达时，本次请求避让共用该入口的账号。
- 原生续接遇到可恢复的容量拒绝时，迁移账号绑定并返回完整历史重试指令，避免将旧账号的增量请求发给新账号。
- 统一 HTTP、SSE 和 WebSocket 的恢复错误及等待提示；严格亲和模型受限时提供具体原因。
- Codex 与 Claude 使用记录均支持按历史账号名称或邮箱搜索，查询参数为 accountSearch；旧参数 accountName 返回 400。

## 部署与质量检查

- 一键安装自动生成部署密码，应用首次启动自动创建 veil 主密钥和映射库；重建容器继续复用持久化数据。
- 修正重复安装意外更新镜像、密码空白校验和健康检查受宿主机代理影响的问题；按实际映射端口检查服务，并限制下载及就绪等待时间。
- 恢复适用于当前二开业务的后端测试，补充 Claude、veil、请求恢复、代理避让及账号搜索回归检查，并接入 CI。
- 前端构建镜像固定为 Node 26.13.1；main 构建继续发布 latest 和 sha 标签，正式 Release 使用版本号和 stable 标签。

## 升级须知

- 继续使用 CPRS 独立的数据库初始化基线，不支持直接接入源仓库或旧定制版数据库。本次请求恢复与筛选改动无需新增数据库迁移。
- 已有 CPRS 部署需保留配置、PostgreSQL、Redis 和 .runtime/data，尤其是 veil 主密钥及映射数据。
- 管理端在线更新按主版本隔离；从旧 3.x 编号切换到 CPRS 4.x 时使用 Docker 镜像更新或手动替换二进制。
