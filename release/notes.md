# v4.0.3

## Claude 账号管理

- 补齐账号基础资料入口，展示已保存的名称、邮箱、用户 ID、组织 ID 和套餐；基础身份与官方个人统计、订阅周期独立表达，未知信息保持未知。
- 五小时和通用周额度接入账号周期用量，展示 CPRS 请求的 Token、缓存和模型明细，模型专属窗口不重复计入账号总量。
- 开放额度预测，历史额度与累计用量按响应头观测时间配对；套餐变化、重置和样本不足按实际观测处理，月结果标为折算。
- 支持五小时和周额度阈值，达到阈值暂停调度，取得完整恢复观测后解除；查询失败及旧套餐、旧周期的迟到响应不能错误解除或重新触发暂停。
- 展示官方 OAuth 资料提供的订阅开通时间、状态和计费类型；当前账期、续订等未提供的信息保持未知。

## 重置权益库存

- 通过当前 OAuth 查询 Claude 重置权益，展示库存状态、有效期和作用范围；已在 OVH 部署账号验证真实查询响应。
- Claude 本期仅开放库存查询，消费端点、幂等和结果核对合同仍待核实，尚未开放消费；自动消费能力始终关闭，并在页面、配置接口和后台执行处统一拦截。

## 用量与费用展示

- 使用记录列表和详情共用请求时保存的费用、单价和缓存明细；分项与账本总额核对后展示，不使用当前价目重算历史记录。
- 流式后续用量无法计价时清除旧费用分项，计量及计时更新保留完整额度观测。
- Claude 首响应载荷计时对齐 Codex，思考和正文到达时间继续独立记录，注释和空 SSE 帧不补造首响应时间。
- thinking 胶囊只显示 `thinking`，模式和预算放在提示中，推理强度单独展示。
- Claude 费用卡片展示真实计费档位、速度模式、标准费用及倍率，历史费用继续使用请求时的价格快照。
- Claude 请求补充选号等待与账号池槽位观测；上游未提供的性能数据不补造。
- 分析统计的日期选择按部署业务时区查询，避免浏览器时区改变日期范围。

## 隐私策略与本地验证

- 隐私策略页只读展示 Veil 生效规则、内置或自定义来源及白名单；词典规则仅展示数量，避免回显受保护的字面量。
- 补充额度时间配对、暂停恢复、费用快照、流式计时、能力门禁和界面展示的回归覆盖。
- 本地 Rust 开发和测试配置关闭调试符号与增量缓存，减少验证产物占用。

## 构建与发行

- main 的成功 CI 驱动提交镜像和 latest 发布，提升前重新核对源码与 CI；仅发布索引变化时可沿用原提交的检查结果。
- 手动入口与 tag 共用 Linux amd64、arm64 发行流程，补齐版本镜像保护、稳定通道和网页更新索引的失败恢复。
- 清理失效的协作与部署说明，恢复项目开发和发行技能；仓库保护规则以待管理员应用的配置文件提供。
- 将传递依赖 `quinn-udp` 更新到 `0.5.16`，修复 RustSec 公告 `RUSTSEC-2026-0538`。

## 升级说明

- 本版不新增数据库迁移或预测历史表，复用现有账号凭据、额度和请求观测存储。
- 重建应用容器时保留现有配置、PostgreSQL、Redis 和 `.runtime/data`，尤其是 Veil 主密钥及映射数据。
